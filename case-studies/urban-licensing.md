# Urban Licensing Document Automation

Preparing a document in my municipal urban licensing workflow used to take 30–60 minutes. I built a tool that generates documents from uploaded applicant files and predefined templates. I now prepare each document in five minutes or less.

## Workflow

1. Upload the applicant's files.
2. Generate the required documents using the appropriate templates.
3. Use the generated documents in the licensing workflow.

## Technical details

I built the application with Python, Node.js, Tailwind CSS, and API integrations, using Antigravity during development.

The time comparison describes my own workflow per document. The [PermitDocs Demo plan](../project-plans/permit-docs-demo.md) outlines a standalone version of the workflow using fictional records and templates.
