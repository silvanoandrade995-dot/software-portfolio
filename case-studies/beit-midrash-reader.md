# Beit Midrash Reader

Beit Midrash Reader is a local reading application for exploring Jewish literature. A reader can search for a specific volume through the Sefaria API and view the original Hebrew or Aramaic with transliteration and Brazilian Portuguese translation.

## Demonstration flow

1. Search for a volume in the app.
2. Open the result.
3. Read the original, transliteration, and translation alongside one another.

## Implementation

I defined the product concept and structured a working prototype using AI-generated code. The stack includes Python, Node.js, Tailwind CSS, and external APIs.

## Status

The prototype runs locally. This page describes the current reading flow.
